# نظام التصميم العربي المعياري (Djadwal Arabic Design System) — المهمة P10

تاريخ الإصدار: 3 نوفمبر 2026  
الفرع: `p10-arabic-design-system`  
الحزمة المستقلة: `@djadwal/ui` (`packages/ui/`)  
المشروع: نظام Djadwal لإدارة الجداول والامتحانات — جامعة الشهيد حمه لخضر بالوادي

## 1. الفلسفة المعمارية ومبادئ التصميم (Design Philosophy)

تم بناء نظام التصميم العربي `@djadwal/ui` كحزمة نقية ومعزولة تماماً تخدم التحول التدريجي إلى واجهة مستخدم حديثة وسريعة دون المساس ببيئة الإنتاج الحية أو الواجهة الكلاسيكية المعتمدة:

1. **العربية أولاً (Arabic & RTL-First):**
   - كافة المكونات مبنية بخصائص CSS المنطقية حصرياً (`padding-inline`, `margin-block`, `inset-inline-start`, `border-inline-end`).
   - خلو تام ومفحوص آلياً عبر ESLint من الاتجاهات الفيزيائية القديمة (`pl-/pr-`, `ml-/mr-`, `left-/right-`, `text-left/text-right`).
2. **إمكانية الوصول الشاملة (WCAG 2.2 AA Compliance):**
   - مؤشرات تركيز بصرية واضحة (`focus-visible:ring-2`) لكافة العناصر التفاعلية.
   - دعم كامل للتنقل بلوحة المفاتيح والـ Screen Readers عبر سمات `aria-*` و`role`.
   - نسب تباين لونية مدروسة تحقق معايير التباين العالي (≥ 4.5:1 للنصوص العادية).
3. **خلو تام من التبعيات الثقيلة (Zero-MUI & Lightweight):**
   - حظر كامل لأي استيراد من `@mui/*` أو `@emotion/*` داخل الحزمة.
   - بدائل نقية وسريعة وخفيفة تعتمد على معايير الويب الأصيلة وTailwind CSS.
4. **خط عربي متغيّر خفيف وعصري:**
   - استبدال التضمين القديم عبر Base64 بتعريفات خط عربي متغيّر حديثة تعتمد على `font-display: swap` وتقسيم نطاقات الرموز (`unicode-range`) لتقليل زمن حظر العرض (Render Blocking) إلى الصفر، مع ضبط الارتفاع التيبوغرافي `line-height: 1.7` للغة العربية.

## 2. مصفوفة توكنات التصميم (Design Tokens)

تتوفر التوكنات ككائنات TypeScript قابلة للاستيراد (`@djadwal/ui/tokens`) وكمتغيرات CSS Variables داخل `@djadwal/ui/tokens.css` تدعم الوضعين الفاتح والداكن:

### 2.1 لوحة الألوان (Color Palette)
- **اللون الأساسي الأكاديمي (Primary Emerald):**
  - `--dj-color-primary-600`: `#059669` (اللون الرئيسي لجامعة الوادي)
  - تدريجات من `50` (فاتح للأسطح) إلى `950` (داكن للتركيز)
- **اللون الثانوي الإداري (Secondary Indigo):**
  - `--dj-color-secondary-600`: `#4f46e5`
- **الحالات المعيارية (Semantic Statuses):**
  - النجاح (Success): `#16a34a`
  - التحذير (Warning): `#d97706`
  - الخطر (Danger): `#dc2626`
  - المعلومات (Info): `#0284c7`

### 2.2 التباعد الشبكي (4pt Spacing Scale)
- `1`: 4px | `2`: 8px | `3`: 12px | `4`: 16px | `5`: 20px | `6`: 24px | `8`: 32px | `10`: 40px | `12`: 48px | `16`: 64px.

### 2.3 أنصاف الأقطار والظلال (Radii & Elevation)
- **أنصاف الأقطار:** `sm: 4px`, `md: 8px`, `lg: 12px`, `xl: 16px`, `2xl: 24px`, `full: 9999px`.
- **الظلال:** `--dj-shadow-sm`, `--dj-shadow-md`, `--dj-shadow-lg` مع تكيف تلقائي في الوضع الداكن.

## 3. كتالوج المكونات المنجزة (20+ Components Catalog)

### أ. الأزرار وحقول الإدخال (Buttons & Inputs)
1. **`Button`**:
   - الأنماط: `primary`, `secondary`, `outline`, `ghost`, `danger`, `warning`.
   - الخصائص: `isLoading` مع مؤشر تحميل متحرك، `startIcon`, `endIcon`, `size: sm | md | lg`.
2. **`Input`**:
   - حقل إدخال يدعم `startIcon`, `endIcon`, `label`, `error`, `helperText`.
   - ضبط منطقي تام للإزاحة (`ps-10` للأيقونة البادئة و`pe-10` للأيقونة اللاحقة).
3. **`Select`**:
   - قائمة منسدلة مع سهم مدمج في الموضع المنطقي `end-3` مع إمكانية الوصول الكاملة.
4. **`Checkbox`**:
   - مربع اختيار مخصص مع أيقونة تحقق وتسمية منطقية (`ms-2.5`).
5. **`Switch`**:
   - مفتاح تبديل يدعم لوحة المفاتيح (`role="switch"`) والتحويل المتكيف مع RTL (`rtl:-translate-x-5` / `ltr:translate-x-5`).

### ب. الحاويات والنوافذ (Containers & Overlays)
6. **`Dialog` (Modal)**:
   - نافذة منبثقة مع عزل التمرير الخلفي، إغلاق بـ `Escape` أو النقر خارجاً، وسمات `role="dialog"` و`aria-modal="true"`.
7. **`Drawer`**:
   - لوحة جانبية متحركة من اليمين أو اليسار بحسب الاتجاه المنطقي (`side: start | end`).
8. **`Tabs`**:
   - ألسنة وتبويبات مع `TabsList`, `TabTrigger`, `TabContent` وتوافق كامل مع قارئات الشاشة.
9. **`Card`**:
   - بطاقة حاوية مع `CardHeader`, `CardTitle`, `CardDescription`, `CardContent`, `CardFooter`.

### ج. التغذية الراجعة والحالات (Feedback & States)
10. **`ToastProvider` & `useToast`**:
    - نظام تنبيهات عائمة بأربع حالات (`success`, `warning`, `danger`, `info`) مع مؤقت إخفاء تلقائي وسمة `aria-live="polite"`.
11. **`Skeleton`**:
    - هياكل تحميل متحركة بنمطين نبضي ومستدير (`rectangular`, `circular`, `rounded`).
12. **`EmptyState`**:
    - حاوية الحالات الفارغة مع أيقونة وعنوان ووصف وزر إجراء اختياري.
13. **`ErrorState`**:
    - صندوق عرض الخطأ القياسي مع زر إعادة المحاولة.
14. **`ErrorDisplay` (المعياري العربي)**:
    - مكون يعرض بوضوح متطلبات الدعم الفني:
      - ماذا حدث باللغة العربية بوضوح.
      - الخطوة المقترحة للمستخدم لحل المشكلة.
      - رمز التتبع (`traceId`) مع زر نسخ لحظي.
      - زر إعادة المحاولة الفوري (`onRetry`).

### د. عرض البيانات والتنقل (Data Display & Navigation)
15. **`Table`**:
    - جدول معتمد ومتجاوب مع `TableHeader`, `TableBody`, `TableRow`, `TableHead`, `TableCell` بمحاذاة منطقية `text-start`.
16. **`DataGrid`**:
    - شبكة بيانات خفيفة وسريعة تدعم البحث اللحظي، الترتيب التصاعدي/التنازلي، وتصفح الصفحات دون مكتبات ثقيلة (بديل نظيف لـ ag-grid وMUI x-data-grid).
17. **`Badge`**:
    - شارات حالات ملونة (`primary`, `success`, `warning`, `danger`, `info`, `neutral`, `outline`).
18. **`Tooltip`**:
    - تلميحات تظهر عند التحويم أو التركيز بجهات منطقية وموضع تلقائي.
19. **`DropdownMenu`**:
    - قائمة خيارات منسدلة مع عناصر وأيقونات وفواصل وعزل نقرات الإغلاق.
20. **`Breadcrumbs`**:
    - مسار تنقل تسلسلي مع فواصل أسهم متكيفة مع اتجاه الكتابة وسمة `aria-current="page"`.
21. **`Pagination`**:
    - شريط ترقيم صفحات مع علامات الحذف (`...`) وأزرار السابق/التالي.
22. **`Avatar`**:
    - صورة رمزية أو حروف أولى للمستخدم مع مؤشر حالة الاتصال (`online`, `offline`, `busy`, `away`).

## 4. كيفية معاينة المكونات محلياً (Component Showcase)

تم إنشاء صفحة استعراض تفاعلية متكاملة داخل تطبيق Next.js على المسار:
```
http://localhost:3000/design-system
```
(أو عبر المنفذ المعين محلياً، ويمكن الوصول إليها مباشرة من شريط التنقل العلوي عبر زر **«نظام التصميم»**).

### ميزات صفحة المعاينة:
- **مبدل الاتجاه التفاعلي (RTL ↔ LTR):** لاختبار تجاوب المكونات المنطقي فورياً.
- **مبدل الوضع (Light ↔ Dark):** لاختبار التباين وتوكنات الألوان في الوضعين.
- **تجارب حية:** فتح النوافذ (`Dialog`)، الأدراج (`Drawer`)، إطلاق التنبيهات (`Toast`)، والبحث في شبكة البيانات (`DataGrid`).
